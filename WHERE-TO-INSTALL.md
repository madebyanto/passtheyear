# 📲 Where to Install

**Two ways to get PassTheYear on your phone. Pick the one that fits you.**

</div>

---

## ⚡ At a Glance

| | Method | Difficulty | Auto Updates |
|---|---|:---:|:---:|
| 🌟 **Aura Store** *(recommended)* | Add the repo once, manage everything in-app | ⭐ Easy | ✅ Yes |
| 📦 **GitHub Releases** | Download the APK and install it yourself | ⭐⭐ Manual | ❌ No |

---

## 🌟 Option 1: Aura Store (Recommended)

Simple setup, and you'll always stay up to date automatically.

### Steps

1. **Install Aura Store**
   Download it from 👉 [store.aurastudioitalia.it](https://store.aurastudioitalia.it)

2. **Sign in**
   Create an account or log in. You can also sign in incognito.

3. **Open Settings**
   Head to the **Settings** section inside Aura Store.

4. **Add the repository**
   Add this repo URL:

   ```text
   https://github.com/madebyanto/passtheyear
   ```

5. **Restart the app**
   Close and reopen Aura Store.

6. **Done! 🎉**
   PassTheYear now shows up in your app menu, and you can install and update it right from there.

> 💡 **Why Aura Store?** One-tap installs and automatic updates, so you never have to check for new versions again.

---

## 📦 Option 2: GitHub Releases (Manual)

Prefer full control? Grab the APK directly.

### Steps

1. **Open the Releases page**
   Go to 👉 [github.com/madebyanto/passtheyear/releases](https://github.com/madebyanto/passtheyear/releases)

2. **Download the latest APK**
   Pick the newest release and download the `.apk` file from the **Assets** section.

3. **Allow installs from your browser or file manager**
   If Android asks, enable **Install unknown apps** for the app you used to download the file.

4. **Install**
   Open the downloaded APK and tap **Install**.

> ⚠️ **No automatic updates.** To update, repeat these steps with each new release.

---

## ❓ Which One Should I Choose?

- Want it **easy and always up to date**? → **Aura Store** 🌟
- Want **manual control** and no extra store app? → **GitHub Releases** 📦
